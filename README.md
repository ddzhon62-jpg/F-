# Personal Finance — Project Overview

A personal finance web application built with React, Node.js/Express and PostgreSQL. I worked on this project to practise web development, application logic and database-backed features.

## What the application does

- Registers users and provides JWT login.
- Keeps account transactions and statistics separate.
- Creates, edits and deletes income and expense entries.
- Shows totals, balance, categories and recent history.
- Provides a responsive Russian-language interface and Swagger API documentation.

## Technology

React / Vite · JavaScript · Node.js / Express · SQL / PostgreSQL · Docker Compose.

## Verification

The application has backend validation and HTTP integration tests, React component tests and a PostgreSQL 16 CI check. Registration/login and transaction CRUD have also been checked in Chromium on desktop and mobile layouts.

## Repository scope

This repository contains the project overview. The application source is maintained separately in a private repository; this page does not contain runnable application code.

This is a personal learning project, not a commercial financial service.
